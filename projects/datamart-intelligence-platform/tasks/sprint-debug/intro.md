**Debug the broken pipeline.** A teammate shipped a transform and the numbers
are wrong — revenue's too high, a dashboard shows duplicates, a rate reads
`0.1%` instead of `12.5%`. Nobody hands you a clean spec in the real world; they
hand you *broken code and a complaint*. Reading someone else's logic, forming a
hypothesis, and fixing the one wrong line is the daily job.

In this track the scaffold **is the bug** — it runs, but produces the wrong
answer. Each lesson is a bug report: what's wrong, and the fix. Read the buggy
code, find the flaw, correct it.
