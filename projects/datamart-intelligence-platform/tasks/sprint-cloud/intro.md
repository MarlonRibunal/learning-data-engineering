**Cloud & Lakehouse.** The blueprint's cloud sprints (BigQuery, Databricks) run
on services you'd pay for — so instead of making you spin up accounts, this
sprint teaches the *ideas that actually matter* on those platforms, as local,
instant exercises:

- **The cloud cost model** — serverless warehouses like BigQuery bill you by
  **bytes scanned**, which turns "SELECT only what you need" and **partition
  pruning** from tidiness into money.
- **The lakehouse** — Databricks/Delta Lake bring database guarantees to cheap
  object storage: **ACID `MERGE`**, **time travel**, and the **medallion**
  (bronze → silver → gold) architecture.

These concepts transfer directly to BigQuery, Snowflake, Databricks, and
Fabric. Learn them here for free; apply them there for real.
