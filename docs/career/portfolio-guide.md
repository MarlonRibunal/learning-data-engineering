# Turn This Into a Portfolio

You didn't read about data engineering — you **did** it, and a grader checked
every piece. That's rare, and it's your edge. Here's how to show it.

## You already have the projects

Every sprint you cleared is a graded, working project across the full
lifecycle — Query, Ingestion, Transform, Validate, Orchestrate, Process,
Hybrid, Serve, Stream, Real-time, Dashboard, Secure, Design, Production, plus
the Capstone. That's a broader end-to-end story than most bootcamp portfolios.

## Ship the receipts

- **Proof artifacts.** Passing tasks with a `proof` config generate a
  `portfolio/<sprint>-<task>/` folder (a `PORTFOLIO.md` + verified results, and
  a chart when relevant). Commit these — they're evidence the work *ran*, not
  just that you wrote code.
- **A README that leads with outcomes.** Not "I learned dbt" — "Built and
  tested a graded dbt marts layer with correctness assertions." Link the proof.
- **One flagship walkthrough.** Pick the Capstone (a composite dbt + Airflow
  pipeline) and write a short walkthrough: the problem, your design, one
  trade-off, the verified result. That's your interview centerpiece.

## The three-line résumé bullets

Frame each as *impact → what → how verified*:

- "Built an idempotent ingestion layer (dedup + upsert) validated against
  double-run tests."
- "Implemented event-time windowed aggregations with watermarking for late
  data, verified on a real Spark session."
- "Designed a least-privilege analytics role and a PII-safe view, graded on
  real Postgres privilege checks."

## Then actually apply

Polish your LinkedIn and GitHub to match. Reach out; don't only apply cold. A
public repo of graded, working DE projects is a conversation starter — use it.
